A note on what "collaboration" can mean here

Google Project Zero is an organisation, and GitHub only supports user accounts as outside collaborators, so an invite to googleprojectzero is not possible and was refused with "not a user". Collaboration with them properly means either a pull request to their repository or a named individual accepting an invitation. Attribution here does not imply their endorsement, and no invitation is pending.
