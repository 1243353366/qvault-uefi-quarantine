persistence

Behaviour ATT&CK Coverage Control Limit
autostart-appinit T1546.010 — Event Triggered Execution: AppInit DLLs implemented persistence.appinit_dll: a populated value is unexpected on modern Windows only observes the value; a DLL already loaded into running processes is not seen
autostart-boot-execute T1547.001 — BootExecute value under Session Manager (folded into T1547.001) implemented persistence.boot_execute: strict equality against 'autocheck autochk *', which catches a payload appended to the default chkdsk legitimately adds temporary entries; detection is not attribution
autostart-ifeo T1546.012 — Event Triggered Execution: Image File Execution Options Injection implemented persistence.ifeo: alert on a Debugger value outside Program Files or on any security-relevant image appcompat shims set Debugger legitimately, so a value alone is not malicious
autostart-run-keys T1547.001 — Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder implemented persistence.run_key / startup_folder / policies_run: read the autostart set and compare against the golden image rather than alerting on key writes an offline image read only; a live registry read is a self-report and grades nothing
autostart-scheduled-task T1053.005 — Scheduled Task/Job: Scheduled Task implemented persistence.scheduled_task: hidden flag, SYSTEM principal, writable command the TaskCache tree is full of legitimate tasks; volume is not evidence
autostart-service T1543.003 — Create or Modify System Process: Windows Service implemented persistence.service: flag a binary or ServiceDll outside System32 and require a signature per service a signed malicious service, or a legitimate binary with a malicious config, passes
autostart-wmi-subscription T1546.003 — Event Triggered Execution: WMI Event Subscription absent none in this repository an autostart snapshot does not read the WMI repository; this is a known gap and is listed as one rather than inferred away

pre-os

Behaviour ATT&CK Coverage Control Limit
chain-of-trust-bypass T1553.006 — Subvert Trust Controls: Code Signing Policy Modification partial firmware_integrity anchor classes; reported as a declared class, not a verified one QVault records the anchor class and refuses to promote on it; it does not verify Secure Boot itself
persist-bootkit T1542.003 — Pre-OS Boot: Bootkit partial firmware_integrity: measured boot with a hardware anchor, plus an out-of-band flash read against a golden reference requires hardware measurement; without an anchor the claim stays HYPOTHESIS at any number of sources
persist-system-firmware T1542.001 — Pre-OS Boot: System Firmware partial firmware_integrity anchor classes with a grade ceiling per anchor type an OS-mediated firmware read is UNKNOWN by design; only an out-of-band read supports a claim
