Reading this site without trusting it

The site is a build product. tools/build_docs.py renders it from the Markdown in the repository, a gate fails the push if the published HTML is stale against those sources, and a second gate fails if any claim lacks a source or a grade. Where a page and the code disagree, the code is what runs, and the disagreement is a defect worth reporting.
